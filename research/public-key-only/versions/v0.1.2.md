# v0.1.2 — First-use rekey burst correction
Date: 2026-08-09

## Major model correction
The previous working model treated early `SystemFunction036` calls as approximately one KSecDD rekey each. Exact reference-source control flow shows a different possibility.

On a first-use RC4 entry, `RandomFillBuffer()` rekeys the selected entry, then sets its **local** `RC4BytesUsed` to the rekey threshold. The subsequent max-output calculation therefore yields zero bytes for that pass. `GenRandom()` loops without advancing its output counter and selects the next entry.

With eight user-mode entries and selector order `1,2,3,4,5,6,7,0,...`, the source semantics predict:

`one initial GenRandom request -> 8 first-use rekeys with 0-byte output -> 9th pass returns bytes from entry 1`.

This means the earlier equation `one SystemFunction036 call = one KSecDD transition` is no longer an admissible assumption. Exact SP3 call nesting is now a top-priority binary/trace proof obligation.

## Strong conditional dimensional collapse
Because the first eight source-semantic passes emit zero bytes, the original 20-byte caller buffer B remains unchanged while `UpdateCircularHash()` is called repeatedly.

With zero initial `CircBuf`, MD4 mode, increment 7:

`D = MD4(B)`

`C_j = C_{j-1} XOR E_{7(j-1)}(D)` for j=1..8.

Therefore the complete user-side first-eight rekey-input tuple `(C1,...,C8)` has image at most `2^128`, conditional on the first-use burst and no interleaving. It is not eight independent 256-byte states.

## SP3 anchor already confirmed
V17's first observed KSecDD input is exactly:

`C1 = MD4(B) || 0^240`

for the captured pre-call 20-byte B. This relation is bit-exact. Existing V17 notes also state that the first eight KSecDD IOCTL outputs initialize the eight ADVAPI RC4 states before later PRGA reuse, which is consistent with the burst model but does not yet prove API-call nesting.

## Remaining root
Even if the entire ADVAPI first-use user-side input family collapses to 128 bits, KSecDD still evolves:

`X_j = F(X_{j-1}, P_j)`

and returns rekey material by transforming each C_j with a stream derived from X_j. Thus no PK-only break is proven until the joint effective dimension of `(X0,P1,...,P8)` is reduced or structurally bypassed.
