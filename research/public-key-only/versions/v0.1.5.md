# v0.1.5 — Reachable-image reframing + six-root early Windows ancestry

Date: 2026-08-09

## Research framing change
The project is now centered on the **reachable private-key image** of the exact historical stack rather than treating `Public-Key-Only` as the object of study.

Let `omega` denote all hidden execution state admitted by a fixed implementation/build class `C`, and let:

`d_first = Phi_C(omega)`.

The primary object is:

`R_C = Image(Phi_C)`.

The desired structural quantity is an upper bound on:

`B_C = log2 |R_C|`,

plus the cost/structure required to enumerate or otherwise search `R_C`.

Public-key-only recovery becomes a corollary/attack model: if `R_C` is efficiently searchable below the generic secp256k1 ECDLP baseline (~2^128 group operations), the public key `Q=dG` serves only as the verifier for candidates generated from `R_C`.

## New confirmed finding F007
V17 raw SP3 trace + KSA replay maps the first four useful SystemFunction036 outputs to KSecDD-derived ADVAPI RC4 roots as:

`R1 <- M1 segment 0`

`R2 <- M1 segment 1`

`R3 <- M2 segment 0`

`R4 <- M3 segment 0`.

The first two outputs are consecutive 20-byte segments from the same cached entry1 RC4 stream. KSA replay independently identifies PRGA #10 with IOCTL #2 and PRGA #11 with IOCTL #3.

## First-key composition consequence
The already-fixed standard first-key call sequence consumes seven SystemFunction036 outputs:

- poll #1: init + acquire + 2 runtime blocks = 4;
- poll #2: acquire + 2 runtime blocks = 3.

Continuing the selector state after the startup transient gives the KSecDD-root ancestry:

`[M1, M1, M2, M3, M4, M5, M6]`.

Therefore only six KSecDD rekey roots are consumed by the modeled seven Windows RNG outputs. `M7` and `M8` are created during startup but do not lie on this first-key dependency graph.

This is an ancestry/image-domain reduction, not a claim that the six roots are independent or that their joint support is six times 256 bits. The next task is precisely to determine whether `M1..M6` are themselves projections of a much smaller persistent kernel state/history root.
